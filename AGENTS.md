- Nested-overlay close must be deferred (`setTimeout(..., 0)`) whenever the close is triggered synchronously by a pointer event (button click / dialog X / ESC): Radix processes the pending pointer-down-outside against the parent AFTER React re-renders with `hasSubOverlay=false`, so an immediate close unmounts the guard → parent dialog closes. Async-triggered closes (mutation onSuccess) need NO deferral — pointer event already settled.
- Q1 default must not flash MANAGED_STOCK while setting loads → `undefined` until `imEnabled` resolves.
- Drafts = real `Product` rows (`status='draft'`, `isActive=false`) — NOT localStorage; multiple drafts = multiple rows; publish validates name + non-negative price then `status='active'`/`isActive=true`; storefront excludes drafts via `status: { not: 'draft' }` regardless of `isActive`.
